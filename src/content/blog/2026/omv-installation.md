With my newly aquired laptop I wanted to setup something so I could easily share files across my network and have a place to store backups. I had heard good things about OpenMediaVault and decided to give it a try and spin a instance up on the proxmox server.
<br><br>
The installation process was pretty straightforward, and I had it up and running in no time. I used proxmox ve scripts to quickly create a new vm and install openmediavault on it. Once it was installed, I was able to allocate another partition on the proxmox server to the vm and use it as a storage drive for openmediavault.
